This is a simple PowerShell script that toggles the Loudness Equalization option in Windows audio settings between ON and OFF.

I **HIGHLY SUGGEST** that you first set the Loudness Equalization option to **Short** in the Release Time "Settings" button just above "Preview" while Loudness Equalization is highlighted.

Download the .zip file, extract it and keep both .ps1 and .cmd files together in the same folder. The .cmd file is the one that you have to run (it calls for the .ps1 file, which contains the script itself). You can create a shortcut of the .cmd file to your desktop and rename it if you wish.

**DO NOT CHANGE THE .ps1 FILE NAME.**
**KEEP BOTH FILES TOGETHER IN THE SAME FOLDER**
